# Flávia Forcatho English Solutions Webpage

Site estático feito com Vite, React, Tailwind CSS e i18next.

```sh
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # gera o site em dist/
npm run deploy   # publica dist/ no branch master (GitHub Pages)
```

Traduções ficam em `src/locales/` e os preços em `src/data/prices.json`.
